🎬 CineVerse – Movie Explorer

CineVerse is a movie discovery website that lets users explore movies, discover trending and upcoming releases, watch trailers, and manage a personal watchlist.

✨ Features

- Browse popular movies
- Explore trending and upcoming movies
- Search for movies
- Filter movies by genre, year, rating, and language
- View detailed movie information
- Watch movie trailers
- Create a personal watchlist
- Explore streaming availability
- Dark and light themes
- Responsive design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap (if used)
- TMDB API

🚀 Getting Started

1. Clone or download this repository.
2. Configure your TMDB API credentials locally.
3. Open "index.html" using VS Code Live Server.

🔐 API Configuration

Add your TMDB credentials to your local configuration file. Never publish API tokens or secrets to GitHub.
